# projetoMoneyballSenai2
perguntas transformadas:
RF01 – Identificar o jogador com melhor desempenho geral
O sistema deve calcular o desempenho geral de todos os jogadores com base nos critérios definidos pela equipe e exibir o jogador com a maior pontuação.
RF02 – Identificar o jogador com pior desempenho
O sistema deve analisar as estatísticas cadastradas de todos os jogadores e identificar aquele que apresenta o pior desempenho geral.
RF03 – Gerar o ranking dos cinco melhores jogadores
O sistema deve calcular um ranking de desempenho utilizando a metodologia definida pela equipe, ordenar os jogadores de forma decrescente e apresentar os cinco primeiros colocados, informando o critério de cálculo utilizado.
RF04 – Identificar o jogador mais regular
O sistema deve calcular a regularidade dos jogadores por meio de uma fórmula definida pela equipe e apresentar o jogador que possui o desempenho mais consistente ao longo das partidas.
