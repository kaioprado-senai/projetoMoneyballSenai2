Requisitos Funcionais

RF01 – Login de usuários
O sistema deve permitir que os usuários realizem login utilizando e-mail e senha.

RF02 – Controle de usuários
O sistema deve permitir cadastrar, editar, excluir e consultar usuários, conforme seu nível de acesso.

RF03 – Cadastro de jogadores
O sistema deve permitir cadastrar, editar, excluir e consultar jogadores.

RF04 – Importação de jogadores
O sistema deve permitir importar o cadastro de jogadores por meio de planilhas no formato Excel.

RF05 – Consulta de jogadores
O sistema deve permitir consultar informações e estatísticas de um jogador cadastrado.

RF06 – Pesquisa
O sistema deve permitir pesquisar jogadores pelo nome, número, posição ou equipe.

RF07 – Filtros
O sistema deve permitir filtrar jogadores por equipe, posição, temporada, campeonato ou partida.

RF08 – Cadastro de partidas
O sistema deve permitir cadastrar, editar, excluir e consultar partidas.

RF09 – Registro de estatísticas
O sistema deve permitir registrar as estatísticas individuais dos jogadores em cada partida.

RF10 – Histórico do jogador
O sistema deve apresentar o histórico de desempenho de cada jogador, organizado por partidas e temporadas.

RF11 – Visualização de estatísticas
O sistema deve exibir as estatísticas individuais e coletivas dos jogadores.

RF12 – Dashboard
O sistema deve apresentar um dashboard contendo indicadores e gráficos de desempenho dos jogadores.

RF13 – Ranking de jogadores
O sistema deve gerar um ranking dos jogadores com base em critérios de desempenho definidos pela equipe.

RF14 – Melhor desempenho
O sistema deve identificar automaticamente o jogador com o melhor desempenho, considerando os critérios estabelecidos pela equipe.

RF15 – Pior desempenho
O sistema deve identificar automaticamente o jogador com o pior desempenho com base nas estatísticas registradas.

RF16 – Regularidade do jogador
O sistema deve calcular um índice de regularidade para cada jogador considerando seu desempenho ao longo das partidas.

RF17 – Filtro por estatísticas
O sistema deve permitir filtrar jogadores utilizando estatísticas específicas, como pontos, assistências, rebotes, roubos de bola, tocos e eficiência.

RF18 – Diferencial
Gráficos, tema escuro, comparação entre jogadores, pesquisa dinâmica, exportação para PDF e Excel.

RF19 – Segurança
O sistema deve permitir acesso somente a usuários autenticados.


Requisitos Não Funcionais

RNF1 – Escalabilidade
O sistema deve suportar o crescimento da quantidade de usuários, jogadores e partidas sem comprometer significativamente o desempenho.

RNF02 – Controle de acesso
O sistema deve controlar permissões conforme o perfil do usuário (Administrador, Treinador, Analista, etc.).

RNF03 – Desempenho
O sistema deve apresentar os resultados das consultas em até 3 segundos para bases de dados com até 10.000 registros.

RNF04 – Usabilidade
A interface deve ser intuitiva e de fácil utilização, permitindo que um usuário realize as principais operações sem necessidade de treinamento.

RNF05 – Compatibilidade
O sistema deve funcionar nos principais navegadores modernos (Google Chrome, Microsoft Edge e Mozilla Firefox).

RNF06 – Disponibilidade
O sistema deve estar disponível durante todo o período de utilização, exceto em manutenções programadas.

RNF07 – Integridade dos dados
O sistema deve garantir que os dados cadastrados sejam armazenados corretamente, evitando inconsistências.

RNF08 – Confiabilidade
O sistema deve preservar as informações cadastradas, minimizando riscos de perda de dados.

RNF09 – Importação de arquivos
O sistema deve aceitar apenas arquivos Excel válidos para importação de jogadores.

RNF10 – Backup
O sistema deve permitir a realização de cópias de segurança da base de dados para recuperação em caso de falhas.
